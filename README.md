# 💀 DREADFALL 3D (Retro Boomer Shooter)

Классический мясной 3D-шутер от первого лица в духе **Doom**, **Quake** и **Blood**, написанный на чистом **C++ и аппаратно ускоренном OpenGL**, скомпилированный в автономный **`.exe`** файл (без сторонних зависимостей, весит всего ~127 КБ!).

---

## ⚡ Особенности игры

1. **Геймплей старой школы (Quake / Doom)**:
   * Быстрое перемещение, стрейфы с наклоном камеры, распрыжка (Bunny-hop) и рокет-джампы!
   * Мясные ошмётки (Gibs) и брызги крови при попадании и взрывах врагов.
   * Тряска экрана при выстрелах из тяжёлого оружия и получении урона.

2. **Арсенал оружия (переключение на клавиши `1`, `2`, `3`, `4` или колесо мыши)**:
   * **[1] Двуствольный Дробовик (Super Shotgun)**: Мощный залп из 12 картечин в упор.
   * **[2] Плазменная Винтовка (Plasma Rifle)**: Скорострельные сгустки энергии, испепеляющие толпы.
   * **[3] Ракетница (Rocket Launcher)**: Огромный урон по площади (AoE) и возможность совершать **Rocket Jump** под себя!
   * **[4] Бензопила (Chainsaw)**: Ближний бой, распиливающий монстров на куски и восстанавливающий здоровье игрока!

3. **Враги и Босс**:
   * **Импы**: Метают огненные шары, атакуют на дистанции.
   * **Адские Гончие**: Быстрые твари, несущиеся прямо на игрока в ближний бой.
   * **Кибер-Барон (Cyber-Baron Boss)**: Гигантский рогатый демон с пушкой, стреляющий залпами из 3 плазменных сфер!

4. **Бонусы и Паверапы на арене**:
   * **Аптечки (+35 HP)** и **Броня (+35 Armor)**.
   * **Ящики с патронами** для дробовика, плазмы и ракет.
   * **🔥 QUAD DAMAGE**: Фиолетовая сфера в центре арены, умножающая любой урон в **4 раза** на 15 секунд!

5. **Звук**:
   * Встроенный процедурный аудиодвижок через Windows Multimedia API (`winmm.dll`).

## 🎮 Управление

| Клавиша / Действие | Функция |
|---|---|
| **W, A, S, D** | Перемещение (стрейфы) |
| **Мышь** | Свободный обзор 360° |
| **Левая кнопка мыши** | Огонь |
| **Пробел** | Прыжок (Rocket Jump при выстреле ракеты под ноги) |
| **Shift** | Ускорение / Спринт |
| **1, 2, 3, 4 / Колесо мыши** | Выбор оружия (Дробовик, Плазма, Ракеты, Пила) |
| **Escape** | Освободить / захватить курсор мыши |
| **R** | Перезапуск после победы или гибели |

---

## 🚀 Как запустить

Дважды кликните по файлу **`Dreadfall.exe`**!
*(Исходный код в `src/main.cpp`, компиляция через `build.bat`)*.
